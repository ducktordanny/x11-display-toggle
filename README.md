# X11 Display Toggle script

> Just a simple script for my home PC to switch between the two used display modes quickly

> [!WARNING]
> **Disclaimer**: It's only for my own use on a single PC of mine, if you want something similar check your `xrandr --listmonitors` output and change the variables and your other preferences in the script.

# Install

```
$ git clone git@github.com:ducktordanny/x11-display-toggle.git
$ cd x11-display-toggle
$ ./install
```

# Usage

Use the command and see the ✨🪄magic🪄✨ switch between my two prefered display modes:

```
$ display-toggle
```

Optionally add a hosrtcut for it: Settings → Keyboard → View and Customize Shortcuts → Custom Shortcuts.

I use `alt+p`
